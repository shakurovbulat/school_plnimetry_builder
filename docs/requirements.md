# Матрица требований и ограничения

Актуальное описание: `final_bshakurov_application.md` и `final_bshakurov_userscripts.md`.
Первоначальные требования сохранены в `OLD/bshakurov_application.md` и `OLD/bshakurov_userscripts.md`.

| № | Требование | Реализация | Ограничение / проверка |
|---|---|---|---|
| 1 | Ввод естественного языка | Streamlit, FastAPI, до 6000 символов | Пустые строки и управляющие символы отклоняются; API-регрессии |
| 2 | Геометрические объекты | Правила, Ollama JSON, Pydantic | Полнота понимания произвольного текста не гарантирована; подсветка обозначений и чисел, не всех терминов |
| 3 | Числа | Длины, углы, отношения, радиусы, периметры, тригонометрия; дроби/корни | Проверки диапазонов и конечности; отдельного диалога уточнения чисел нет |
| 4 | Отношения | Принадлежность, равенства, параллельность, перпендикулярность, середины, высоты, биссектрисы, часть касаний | Независимые координатные регрессии; не все формулировки и составные конфигурации поддержаны |
| 5 | Координаты | SymPy для элементарных операций, SciPy least_squares, проверка невырожденности и невязок | Не общее точное символьное решение и не доказательство; отказ поиска не всегда означает невозможность |
| 6 | Интерактивный чертёж | Canvas, подписи, окружности и маркеры заданных углов | Matplotlib используется для экспорта, а не интерактивности; универсальные дуги не реализованы |
| 7 | Zoom/pan/reset | Колесо, перетаскивание фона, сброс, обработка pinch | Wheel/pan/reset проверены настоящим Chrome; физический pinch требует ручной проверки |
| 8 | Перемещение точек | Пересчёт API после отпускания; откат при отказе | API и Chrome e2e; свободные вершины тоже могут сместиться; история отдельно не обновляется |
| 9 | PNG/SVG | Matplotlib, PNG 300 DPI, имена с датой | Сигнатуры файлов и браузерное скачивание; отказ браузера записать файл стандартной кнопкой не перехватывается |

## Дополнительные возможности

- История успешных генераций: SQLite через SQLAlchemy, локальное хранение.
- Режим `rules` включается явно; ошибка Ollama не вызывает скрытый fallback.
- Статус Ollama и схема доступны через API; отдельного debug-интерфейса нет.
- Серверы запускаются на loopback. Нет авторизации, квот и защиты для публичного размещения.
- Natasha не используется; текст разбирают правила и локальная LLM.
- Приоритет проверенных конструкций правил явно обозначается в `parser_engine`. Это не независимая нейросетевая оценка качества понимания текста.

## Что не следует считать выполненным

Универсальный разбор школьных задач, доказательство утверждений, полная поддержка произвольных дуг/касательных, автоматическое восстановление исходного рисунка, проверка физических сенсорных жестов и готовность к публичному хостингу.

Результаты воспроизводимых проверок: `verification.md`. Успех на ограниченном корпусе не означает поддержку всех задач ЕГЭ.
